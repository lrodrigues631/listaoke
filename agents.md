# Listaokê - Instruções do Projeto

## Objetivo

Listaokê é um app para criar salas de karaokê compartilhadas em tempo real.

O dono cria uma sala, compartilha um link ou código com os amigos e controla a fila. Os convidados conseguem entrar, ver a fila, entrar ou sair da própria vez e passar a própria vez.

O foco inicial é uso com amigos, via link/PWA. Futuramente o mesmo app poderá virar APK Android usando Capacitor.

## Stack

- React
- Vite
- Tailwind CSS
- Supabase
- JavaScript
- Futuro PWA
- Futuro APK Android com Capacitor
